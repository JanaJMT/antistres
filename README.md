# Zajtra AI

Zajtra AI je jednoduchá mobilná webová aplikácia, ktorá prináša pozitívne veštby a pokojnú chvíľku pre seba. Farebná krištáľová guľa pri každej veštbe mení farby a jemne oživuje obrazovku.

## Funkcie

- Pozitívne veštby — najviac tri za deň; počítadlo sa ukladá v prehliadači a obnoví sa nasledujúci deň.
- Tiché, jednominútové dýchacie cvičenie s jemne pulzujúcou guľou, ktoré možno kedykoľvek ukončiť.
- Responzívny dizajn pre mobilné telefóny aj väčšie obrazovky.

## Spustenie

Otvorte súbor `index.html` v prehliadači. Ak používate VS Code, môžete spustiť lokálny server v termináli príkazom:

```bash
python3 -m http.server 8000
```

Potom otvorte adresu [http://localhost:8000](http://localhost:8000).

## Súbory

- `index.html` — štruktúra a obsah aplikácie.
- `styles.css` — vzhľad, responzívne rozloženie a animácie.
- `script.js` — veštby, denný limit a dýchacie cvičenie.
